# Security policy

## Reporting a vulnerability

Please do not disclose a suspected vulnerability in a public issue.

Use the repository's **Security** tab to open a private vulnerability report:

`https://github.com/magnuslandahl/ExcalidrawVisualizer/security/advisories/new`

Include the affected version, reproduction steps, expected impact, and any
suggested mitigation. Do not include real private drawings or credentials.

## Supported versions

Until the first stable release, only the newest release is supported. Security
fixes are applied to `main` and included in the next rolling and tagged builds.
